# Product Listing Backend

This is the backend repository for the Product Listing application.

## Getting Started

Follow these steps to set up and run the project locally.

### Prerequisites

- Node.js (latest LTS recommended)
- npm (comes with Node.js)

### Installation

1. **Clone the Repository**

   Open the Windows Shell and run:
   ```sh
   git clone https://github.com/aniket12345678/product_listing_backend.git
   ```

2. **Navigate to the Project Directory**
   ```sh
   cd product_listing_backend
   ```

3. **Install Dependencies**
   ```sh
   npm install
   ```

4. **Start the Development Server**
   ```sh
   npm start
   ```

### Project Structure

The repository follows a standard React project structure.

```
product_listing_frontend/
│-- app/
│   ├── config/           # Connection file
│   ├── controllers/      # Controller functions
│   ├── middleware/       # Middlewares
│   ├── models/           # Database tables
│   ├── routes/           # Route handling
│   ├── uploads/          # Upload attachment folder
│   ├── server.js         # Main application file
│-- package.json          # Project dependencies
│-- .gitignore            # Git ignore file
│-- README.md             # Project documentation
```
